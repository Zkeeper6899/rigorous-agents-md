# Contributing

Contributions are welcome if they make the profile clearer, more reusable, or easier to adapt.

## Good Changes

- Make an instruction more precise or easier to follow.
- Add a concrete domain adaptation with clear behavioral impact.
- Improve examples without making the core profile longer than necessary.
- Fix wording, formatting, or translation issues.

## Changes To Avoid

- Adding vague instructions such as "be smarter" or "answer better".
- Turning the profile into a single-domain prompt.
- Adding long checklists that make every answer follow the same structure.
- Adding claims about model behavior without evidence.

## Style

- Prefer concise, testable instructions.
- Distinguish general rules from optional domain-specific rules.
- Keep English and Simplified Chinese versions aligned when changing the core profile.
